# STARLINK Next

纯 HTML 产品原型，用于规划下一代统一曲库访问与运营平台。

## Demo 入口

- `/index.html`：双产品入口
- `/internal/index.html`：内部曲库工作台
- `/customer/index.html`：外部 STARLINK 客户平台

## 产品 1：内部曲库工作台

面向曲库运营、商务、版权等内部角色。重点不是后台 CRUD，而是快速理解、查询、分析和交付曲库。

### 菜单

- 工作台
- 曲库
  - 曲库检索
  - 曲库分析
  - 资产准备
- 歌单
- 客户
- 交付
- AI Agent
- 系统设置

AI Agent 作为全局能力，同时在顶部保留自然语言“问曲库”入口。

## 产品 2：STARLINK 客户平台

面向授权客户。客户基于自己的授权范围访问曲库，自助完成搜索、试听、选歌、上架和内容获取。

### 菜单

- 首页
- 发现音乐
- 我的歌单
- 我的曲库
- 获取记录
- API

外部产品优先保持简单，不暴露内部版权运营、资产准备等复杂概念。

## 当前阶段

首版只确认两个产品的信息架构、一级菜单和基础视觉方向。后续逐页展开页面结构和核心交互。
